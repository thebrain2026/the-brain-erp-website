What you get

Facilities inside Factory OHS

Use it and the plant manager sees machine health before the breakdown — load, bearing, vibration, and units.

Motor load

Live load percentage on the machine you opened — compressor, blower, pump, kiln fan — so overload is seen before the trip.

Bearing heat

Bearing temperature on the same panel, so heat is seen before the motor is lost.

Vibration

mm/s beside load and heat, marked when it is already in warning.

Today versus yesterday

Units (kWh) today against yesterday, with the percent change, so a high-draw day is obvious.

Machine list

Other machines on the line: OK, WARN, or OFF, with load — blower, pump, kiln fan, compressor 2.

Control room

Compressor house as a live console the plant manager can trust — gauges and the machine list together.

Phone health

The same four gauges on an engineer’s phone when he is not in the house.
